BESOIN D'INFORMATIONS ?

Les questions
essentielles.

Retrouvez les premières informations sur le fonctionnement de l'école vidéo.

Comment accéder aux vidéos ? +

Créez un compte puis connectez-vous. Vous pourrez consulter uniquement les formations qui auront été attribuées à votre compte par l'administration.

Comment l'accès à une formation est-il activé ? +

Après votre paiement avec Emmanuel Pay, l'équipe vérifie le règlement puis active manuellement la formation sur votre compte étudiant.

Les vidéos peuvent-elles être téléchargées ? +

Aucun bouton de téléchargement ne sera proposé. La plateforme doit utiliser un accès contrôlé aux flux vidéo et des liens temporaires. Toutefois, aucune solution web ne peut empêcher absolument un enregistrement de l'écran ou une copie réalisée par un moyen externe.

Puis-je regarder les cours à mon rythme ? +

Les leçons seront accessibles depuis votre espace étudiant lorsque la formation correspondante aura été activée sur votre compte.

Comment récupérer mon mot de passe ? +

Depuis la fenêtre de connexion, cliquez sur « Mot de passe oublié » pour recevoir un lien de réinitialisation par e-mail.
